# 历史记录：MVP v0.1

> 已归档。本文仅记录早期原型目标，已被 v0.1.0-alpha.1 的公开文档和当前源码取代。

早期 MVP 验证了一个最小闭环：

~~~text
已授权媒体或适配器收据
        │
        ▼
本地入库与内容包
        │
        ▼
列表、搜索、详情与媒体预览
~~~

原型阶段故意不承诺：

- 完整的平台采集或发布；
- ASR、OCR、镜头和视觉分析开箱即用；
- 无人监督的生成或公开发布；
- 自动安装第三方引擎；
- 跨平台桌面发行；
- 生产级安全与迁移保证。

早期机器路径、真实样例、账号状态、内部任务记录和阶段性交付结论不属于公共项目文档，已从本归档中移除。
