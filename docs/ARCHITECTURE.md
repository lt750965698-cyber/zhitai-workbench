# 架构与信任边界

织台是单用户、本地优先的内容工作台。它把界面、状态管理和第三方能力分成不同信任区，避免把平台登录态和素材直接交给远程页面。

## 组件

~~~text
┌───────────────────────────────────────────┐
│ 浏览器工作台 / Electron 渲染进程          │
│ 展示、编辑、预览、显式确认                │
└───────────────────┬───────────────────────┘
                    │ 回环 HTTP / 受限 IPC
┌───────────────────▼───────────────────────┐
│ 本地节点                                  │
│ API、来源校验、队列、审核门、服务状态      │
└──────────────┬─────────────────┬──────────┘
               │                 │
       ┌───────▼───────┐ ┌──────▼──────────┐
       │ SQLite 索引   │ │ 本地内容包与素材 │
       └───────────────┘ └─────────────────┘
               │
               │ 显式启用的固定适配器
┌──────────────▼────────────────────────────┐
│ 外置采集、分析、生成、通知和发布进程       │
└───────────────────────────────────────────┘
~~~

## 仓库内核心

### 工作台

app 目录包含 React 用户界面。浏览器模式通过回环 HTTP 调用本地节点；桌面模式优先通过 preload 暴露的窄 IPC 调用主进程代理。

渲染进程不应拥有任意 shell、文件系统或网络代理能力。新增 IPC 时需要同时定义允许的 URL、方法、参数、超时和返回数据脱敏。

### 本地节点

local-agent/server.mjs 负责：

- 本地健康、任务、事件和服务状态；
- 知识库路由与内容包索引；
- 采集、分析、生成和发布队列；
- 来源 allowlist、JSON 请求校验和可配置且配置后强制的 HMAC 校验；
- 固定服务命令与互斥关系；
- 公开发布与部分服务控制的人工确认、幂等键、收据和审计事件；
- 对外置引擎的适配。

本地节点只允许绑定回环地址。它不是具有远程用户认证、租户隔离和公网防护的 Web 服务。

### 数据层

织台同时使用：

- SQLite：结构化索引、任务状态、快照、修正和收据；
- 内容包：媒体、metadata、分析产物和相对文件清单；
- 小型 JSON 状态文件：队列、事件或运行时状态；
- 本机凭据存储：钥匙串、权限受限文件或进程环境。

数据库不是唯一真相源：内容包应保留足够的相对路径、哈希与 metadata，以便审计和重建。迁移必须支持预览、幂等和备份后的回滚。

## 外置引擎

外置引擎不属于仓库内核心。它们可能是：

- 回环 HTTP 服务；
- 固定命令启动的本地进程；
- 已登录的浏览器或平台客户端；
- 本地媒体工具、模型或生成服务；
- 通知与远程控制通道。

配置中出现项目名称或接口不表示织台分发该软件，也不表示许可证兼容。详见 [第三方声明](../THIRD_PARTY_NOTICES.md)。

## 数据流

### 入库

~~~text
用户提供已授权素材或分享链接
        │
        ▼
来源校验与适配器
        │
        ▼
下载或本地文件收据
        │
        ▼
媒体校验、哈希、临时目录
        │
        ▼
原子写入内容包并更新 SQLite
~~~

临时下载 URL、解密参数、Cookie 和签名值不得进入公开 metadata、日志、事件或 API。下载失败、媒体不可播放或外置引擎不可用时，状态必须是失败、部分成功或需要处理。

### 分析与生成

分析产物按来源、时间、置信度和不可用原因保存。没有读取画面、音轨或平台指标时，不得推断逐字稿、镜头、播放量或因果结论。

创作队列完成的生成任务会进入本地预览与审核记录。其他导入或适配器产物仍需要使用者主动检查；生成完成不等于内容事实正确、拥有权利或可公开发布。

### 发布

~~~text
本地素材与文案
      │
      ▼
权利、事实、平台、账号、时间人工检查
      │
      ▼
工作台草稿或平台草稿
      │
      ▼
再次显式确认公开发布
      │
      ▼
外置发布器与平台端人工核验
~~~

适配器返回成功只表示命令执行完成。最终可见性、平台审核和账号状态需要在平台端核验。

## 信任边界

### 本地操作系统用户

织台默认信任当前本地用户可以读取其配置与知识库。不防御已经完全控制该用户会话的攻击者。共享电脑应使用独立系统账号和独立数据目录。

### 浏览器来源

任何网页都不应能调用本地节点。允许来源必须精确配置；通配 CORS、任意 Origin 回显和无条件凭据请求都不被接受。

没有 Origin 的本机 CLI、伴生脚本或进程当前被视为与织台相同的操作系统用户，写请求会在满足内容类型等路由条件后放行。这是 Alpha 阶段的明确同用户信任假设，不是远程身份认证。

### 桌面渲染进程

网页内容和渲染进程视为低信任区。主进程只暴露窄接口，并对 URL、路径、方法、参数和响应大小做二次校验。

### 外置进程

外置引擎可能拥有平台登录态、浏览器控制和素材读写权限，应视为高风险独立供应链。使用固定版本、最小目录、回环端口和专用账号；不要让它读取整个主目录。

### 云端服务

模型、生成和通知服务会建立新的数据边界。启用前必须确认上传内容、保留期限、训练用途、地区、子处理者和删除方式。

## 安全不变量

- 本地节点只绑定回环；
- 服务命令不能由浏览器提交；
- 外置 HTTP 地址只允许回环；
- 知识库详情和导出不返回私有文件路径，凭据不得进入状态 API、日志或导出；
- 素材文件必须位于允许根目录；
- 公开发布和部分服务控制需要可见范围和显式确认；
- 验证码、风控和权限异常转人工；
- 缺失能力不伪造结果。

其他本地写接口尚未统一强制签名或确认，因此不能把本地节点暴露给不受信任的本机用户、进程或远程网络。

更多安全细节见 [安全模型](SECURITY_MODEL.md)。
