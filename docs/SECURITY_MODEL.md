# 安全模型

本文描述 v0.1.0-alpha.1 的预期边界，不代表已经完成独立安全审计。

## 保护目标

- 平台 Cookie、Token、二维码、密钥和账号会话；
- 私聊、评论、订单和其他个人数据；
- 本地素材、知识库和分析产物；
- 发布账号、可见范围和排期；
- 本地文件系统与子进程执行权限；
- 审核记录、收据和数据完整性。

## 假设

织台面向单个本地操作系统用户。默认假设：

- 操作系统和当前用户会话未被完全攻陷；
- 本地配置由使用者控制且权限适当；
- 本地节点只绑定回环；
- 外置引擎在独立目录、固定版本和最小权限下运行；
- 使用者只处理有权操作的账号和内容。

织台不提供公网多租户认证、租户隔离、远程管理平面或恶意本地管理员防护。

## 主要威胁

### 恶意网页调用本地节点

控制措施：

- 精确 allowedOrigins；
- 预检与请求来源校验；
- JSON 内容类型检查；
- 公开发布和部分受管理服务动作需要确认标记；
- 桌面模式使用受限 IPC。

剩余风险：用户把任意来源加入 allowlist、通过代理移除来源信息，或不受信任的本机进程以无 Origin 请求调用写接口。

### 任意命令或参数注入

控制措施：

- 命令、参数和工作目录来自本地配置；
- 子进程使用参数数组和 shell false；
- 浏览器不能提交任意命令；
- 服务列表与动作固定。

剩余风险：配置本身被篡改，或外置程序解释参数时存在漏洞。

### 文件越界与符号链接逃逸

控制措施：

- 配置允许素材根目录；
- 读取前解析 realpath；
- 内容包只保存相对路径；
- 媒体 Range 校验；
- 临时目录和原子移动。

剩余风险：并发替换、上游程序写入不可信链接或操作系统文件系统差异。

### 收件入口伪造与重放

控制措施：

- 节点只绑定回环地址；
- 带 Origin 的请求必须命中 allowlist；
- 无 Origin 的本机客户端被视为同一用户信任边界；
- 可选签名兼容模式在请求携带签名且配置密钥时使用 HMAC-SHA256、时间窗、随机 nonce、nonce 缓存和常量时间比较；
- 远程控制器另行限制发送者和固定命令。

剩余风险：签名不是强制认证；任何能以同一用户访问回环端口的本机进程都可能发起无 Origin 请求。共享密钥泄漏、发送端日志泄漏和本地时间严重漂移也会影响可选签名模式。不要把本地节点暴露到网络或与不受信任的本机用户共享。

### 凭据与隐私泄漏

控制措施：

- 钥匙串或权限受限文件；
- 知识库详情和导出剥离私有文件路径，错误路径有专门脱敏；
- 临时下载 URL 与稳定来源分离；
- 浏览器会话令牌只保留在内存；
- 默认不上传素材到云端。

剩余风险：外置引擎可能自行记录敏感数据、截图或崩溃转储；Alpha 阶段的本地健康、配置或启动诊断也可能显示经折叠或隐藏父目录后的知识库位置。分享任何诊断前仍需人工复核。

### 未经审核的公开发布

控制措施：

- 区分工作台草稿、平台草稿和公开发布；
- 显式确认标记；
- 素材、账号、平台和排期预览；
- 幂等键、收据和状态机；
- 验证码、登录失效和风控转人工。

剩余风险：外置发布器语义变化、平台显示状态与 CLI 返回不一致。

### 供应链

控制措施：

- 外置引擎默认未配置；
- 手工集成要求固定版本、许可证和校验和；
- 不打包许可证不明确的源码；
- 更新前预览，更新后健康检查；
- 契约测试使用模拟器。

内建可选更新器只核对标签、内部版本、部分资产大小和个别 MD5，没有为所有组件验证发布者签名或强加密校验和。MatrixMedia 安装还会修改 Info.plist 并进行 ad-hoc 重签名。

剩余风险：上游发布被替换、传递依赖被投毒、安装脚本执行额外动作，或本机修改使原始代码签名不再可验证。便利更新器不能替代独立供应链核验。

## 部署基线

1. 使用专用的非管理员本地账号；
2. host 保持回环地址；
3. 外置端口也只绑定回环；
4. 不使用公网隧道、端口转发或反向代理；
5. 数据目录和密钥文件仅当前用户可读；
6. 不让外置引擎读取整个主目录；
7. 使用专用平台账号并启用平台侧二次验证；
8. 对公开发布使用内建确认门；对其他高影响动作在操作流程中另行人工确认；
9. 定期备份并验证恢复；
10. 监控安全公告并固定依赖版本。

## 日志与诊断包

允许保留：

- 时间、模块、状态码和内部任务 ID；
- 已归一化的错误类别；
- 不含查询签名的域名或接口名称；
- 版本与健康状态。

不得进入可分享的日志或诊断包：

- Cookie、Authorization、密钥和二维码；
- 手机号、邮箱、真实用户名和私聊正文；
- 临时下载 URL、解密参数和完整页面 HTML；
- 未脱敏的主机绝对路径和用户目录；
- 未经授权的媒体或原始响应。

## 事件响应

疑似泄漏或绕过时：

1. 停止本地节点和受影响外置引擎；
2. 断开网络或暂停相关账号自动化；
3. 撤销并轮换凭据；
4. 备份必要证据，但先脱敏；
5. 确认受影响版本、数据和动作；
6. 按 [安全政策](../SECURITY.md) 私下报告；
7. 修复后从可信版本恢复并复核平台端状态。
